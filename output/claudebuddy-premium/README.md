The three feature showcases contain clearly labelled illustrative interfaces and fictional sample data. They are promotional illustrations, not actual product screenshots. Existing production-rendered listing screenshots remain available in the release-candidate assets.

The selected source logo and extension toolbar circles are unchanged. The three logo files are existing approved exports. Promotional artwork is generated with built-in imagegen, with one independent call for each design. Exact prompts and source references are recorded in `prompts.json`; high-resolution generation masters are kept in `assets/branding/premium-sources/` in the project. Final images are exported at the dimensions above without combining them into a board.

`Agent-Prompt.md` explains how to repeat the workflow using an approved logo, product context and optional style reference. `ClaudeBuddy-Premium-Promo-Pack.zip` contains the individual files, this inventory and prompt records.
