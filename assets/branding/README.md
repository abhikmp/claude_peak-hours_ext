# ClaudeBuddy mascot

`claudebuddy-crab.png` is the user-selected coral paper-cut crab on dark slate. The user supplied the source on 26 October 2026 and requested removal of its corner sparkle on 27 October. The edit is recorded in [logo-cleanup.json](logo-cleanup.json); the previous source and intermediate exports remain in Git history and local working files.

Run `python tools/render-icons.py` with Pillow to export the 16/48/128px brand icons and separate 16/32/48/128px green/orange/red toolbar circles. The source is excluded from the runtime ZIP; exported icons are explicitly allowlisted. Current Store-ready artwork and screenshots are maintained in `images/store/`. Intermediate promotional artwork, generation experiments and video files are excluded from the maintained source tree.
